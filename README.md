# 任意门卷 · TOON LIBRARY

一排会走动的书：九本互动书卷，每本打开都通往不同的内容空间。

## 在线访问

启用 GitHub Pages 后，可从仓库的 Pages 地址打开。

## 使用说明

- 滚轮、方向键或页面按钮切换书卷。
- 选择书卷后点击 `OPEN` 查看详情。
- 支持声音开关和音量调节；浏览器要求先进行一次用户操作才会播放声音。

## 来源与授权

3D 书架交互基于 [MengTo/complete-shelf](https://github.com/MengTo/complete-shelf) 改编，并已获得原作者授权。书卷内容、封面和扩展页面由本项目整理与制作。

## 技术

静态 HTML、CSS、JavaScript 与 Three.js，无需后端服务。
